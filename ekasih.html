eKasih (Pangkalan Data Kemiskinan)

Sistem pangkalan data rasmi kerajaan untuk mengenal pasti isi rumah miskin dan miskin tegar. Status eKasih mempengaruhi kadar SARA dan kelayakan bantuan JKM tambahan.

Kenapa eKasih Penting?

  • Penerima eKasih (miskin / miskin tegar) mendapat SARA lebih tinggi (contoh RM200/bulan berbanding RM100)
  • Digunakan sebagai rujukan untuk banyak bantuan JKM dan program lain
  • Data dikemas kini melalui siasatan di peringkat daerah / negeri

Cara Semak / Kemas Kini

  • Layari portal eKasih atau hubungi Pejabat Kebajikan Masyarakat / Unit Pelaksanaan Daerah
  • Jika rasa sepatutnya berstatus miskin tegar tetapi tidak, buat aduan / permohonan semakan di pejabat daerah
  • Pastikan maklumat STR dan pendapatan dikemas kini kerana data saling berkaitan
Status eKasih tidak boleh “mohon” seperti STR. Ia ditentukan melalui proses siasatan rasmi.
