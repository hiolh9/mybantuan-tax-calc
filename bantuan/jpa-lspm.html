JPA Lepasan SPM (LSPM / Program Penajaan)

Jabatan Perkhidmatan Awam (JPA) — Penajaan penuh (yuran + elaun) mengikut program

Ringkasan

Liputan: Penajaan penuh (yuran + elaun) mengikut program

Kelayakan: Warganegara; SPM cemerlang (biasanya 9A+ untuk program utama); lulus temuduga

Ikatan: Pinjaman Boleh Ubah / ikatan perkhidmatan kerajaan

Status: Biasanya dibuka Mac–April; semak portal JPA

Dokumen lazim

  • MyKad
  • Transkrip / sijil SPM
  • Dokumen kokurikulum

Langkah am

  1. Baca syarat di portal rasmi
  2. Sediakan dokumen
  3. Isi borang dalam talian
  4. Hantar sebelum tarikh tutup
  5. Pantau keputusan / temuduga
